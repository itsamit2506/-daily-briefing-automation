# Daily Briefing Automation Skill

## Overview
The Daily Briefing Automation skill generates personalized daily digests by aggregating information from multiple sources into one actionable message.

## Problem Solved
Users typically spend 30+ minutes each morning checking weather apps, portfolio trackers, news websites, task managers, and calendar apps. This skill consolidates everything into a single, automated briefing.

## Features
| Feature | Description |
|---------|-------------|
| Weather Forecast | Current conditions and 7-day outlook |
| Portfolio Tracking | Real-time performance updates |
| News Digest | Curated headlines by topic |
| Task Overview | Priority tasks for today |
| Calendar Summary | Today's events and reminders |
| Automated Delivery | Scheduled daily delivery via Telegram/Slack |

## Installation
1. Clone: `git clone https://github.com/YOUR_USERNAME/daily-briefing-automation.git`
2. Install: `ironclaw skill install daily-briefing-automation`
3. Configure: Edit `config/settings.json`
4. Run: `ironclaw skill run daily-briefing-automation generate`

## Usage
- Generate briefing: `daily-briefing-automation generate`
- Get weather only: `daily-briefing-automation weather`
- Portfolio summary: `daily-briefing-automation portfolio`
- News digest: `daily-briefing-automation news`

## Configuration
Edit `config/settings.json` to customize:
- Location (city, coordinates)
- Portfolio addresses to track
- News topics of interest
- Delivery channel and time
- Timezone settings

## API Integrations
- Open-Meteo API for weather (free, no key required)
- Portfolio tool for investment tracking
- Web search for news aggregation
- Message tool for delivery
